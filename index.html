Как добавить расписание на главный экран?

iPhone: откройте эту страницу в Safari → «Поделиться» → «На экран Домой» → «Добавить». Если есть переключатель «Открывать как веб-приложение», включите его.

Android: откройте страницу в Chrome → меню ⋮ → «Добавить на главный экран» или «Установить приложение».

Для офлайн-работы один раз откройте установленное расписание с интернетом. Список занятий хранится внутри приложения.

Чтение общих записей без регистрации

Каждый может добавлять ДЗ и модули. Отмены и переносы пар доступны только редакторам.

ДЗ и модули может публиковать любой студент без регистрации. При первом добавлении Supabase создаёт анонимный ID; он сохраняется только в этом браузере. Автор может править своё, редактор — записи группы. Не публикуйте личные данные. Общий архив всех групп доступен в настройках и календаре; перенос выполняется только по нажатию. Изменения расписания не являются официальными сообщениями КГМУ.

📣 Управление объявлениями · администратор

Новость видна на стартовом экране подходящих групп. Можно выбрать отдельную группу, поток, курс, направление или всех пользователей. Только учётная запись глобального администратора может публиковать, редактировать и удалять объявления. Это сообщения студенческого проекта, не официальный канал КГМУ.

Серверный архив включает ДЗ, модули, изменения занятий и объявления; не включает SQL-схему и учётные записи Auth. Публикуйте локальные записи только после резервной копии.
